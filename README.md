# Underlords Wiki

Long-form reference mirror for the Underlords archive, designed like a television / movie-universe wiki rather than an archive dashboard.

The canonical public Underlords experience now lives in `bossmugen/underlords`: character stories, the single Chronicle, Lore, Archive, and the primary public navigation. This repository remains the deeper reference companion for dossiers, episodes, relationships, legends, relics, quotes, locations, and continuity support where that extra indexing adds value without competing with the main site.
