# UNDERLORDS PUBLIC COPY RULES

These rules apply to every reader-facing Underlords wiki page, biography, episode, location, relationship page, label, caption, meta description, and OG title.

1. Never write what something is NOT. Corrections belong in Sources with a ⛔ WRONG tag.
2. Vary joke structure. The setup → comma → deadpan institutional reversal construction is allowed at most twice per page. Some entries get no joke.
3. Escalating noun lists: one per page maximum.
4. Number things only when order carries meaning. Menus and shelves are not sequences.
5. Every factual claim gets a receipt tag inline: 🟩 RECEIPTS, 🟦 MUGS SAID SO, 🟨 HEAR ME OUT, ⬜ UNKNOWN, ⛔ WRONG. If a claim cannot be tagged, cut it or mark it ⬜ UNKNOWN.
6. No vague authority adjectives. Replace them with a date and an action.
7. Every abstract bullet must link to a dated incident or be deleted.
8. Never publish real-life identifying details — employer, military service, location, ethnicity, health, or equivalent real-world identifiers — unless the source note explicitly records consent for public publication.
9. Meta description and OG title are per-page and about that page's subject.
10. No timeline label may say `current`. Use a year.

⛔ WRONG is Sources-only. Real-life details without explicit public consent stay backstage. Existing copy without a safely joined source defaults to ⬜ UNKNOWN.
